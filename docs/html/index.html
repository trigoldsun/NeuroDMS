怎么用这三份手册

第一次用

先读「场景操作」的 §0

空间、权限档位、密级、外链票据这四个词不理解，后面每个页面都会看得别扭。四个概念读完大约三分钟。

不知道能不能做

查「角色能力」的能力矩阵

点表头的角色名，整列会高亮。实心点＝默认可做，空心圈＝需显式授权，横线＝不可做。

要交付 / 验收

读「管理员手册」§3 与 §13

§3 是每个参数的真实含义与取值边界，§6 是空间台账与移交，§13 是已知限制——实施评估时按它做预期管理，比事后解释省事。

这套手册的三条约定

一

不谈功能清单，只谈落点

每个流程都写明"谁做、在哪做、注意什么"。界面上有但系统不读的开关，一律不写——那属于缺陷，不是功能。

二

边界写在功能旁边

"不能做什么"和"什么情况下会被拒绝"与正流程同等重要。例如：能内部分享 ≠ 能外发；管理角色 ≠ 内容权限。

三

图与表可以互相对照

流程图里的圆形序号与下方步骤表的编号一致。看不清图时直接看表，记不住步骤时看图。
