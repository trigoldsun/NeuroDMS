# DESIGN.md · NeuroDMS 产品宣传

## 全局视觉约定

### ① 画布与安全区
- 1280×720；padding 上下 60 / 左右 60；内容区 1160×600
- 页脚（仅内容页）：顶边 y=670，左端 x=60，右端 ≤1220，14px

### ② 配色（金融深蓝 + 青铜强调）
| 槽位 | Hex | 用途 |
|---|---|---|
| 主色 | `#1B3B6F` | 深色块、编号、标题强调 |
| 辅色 | `#5B7899` | 次级线条、图表第二序列、说明文字 |
| 强调色 | `#C08A3E` | 关键数字、CORE 标注，全篇 ≤10% |
| 底色 | `#FFFFFF` | 页面背景 |
| 浅底 | `#F4F6F9` | 卡片底、结论条 |
| 正文 | `#16202E` | 主文字 |

纪律：主色主导；强调色一页最多 2 处；禁阴影；圆角统一 8px（大色块 12px）。

### ③ 字体
- 中文：微软雅黑；西文：Arial
- 阶梯：封面 68 / 巨型数字 96 / 页面主标 34 / 卡片小标 22 / 正文 18 / 注释 14

### ④ 视觉母题
- 内容页标题左上（34px Bold），标题下 1px 贯通细线 `#D8DEE7`；右上角章节小字（14px，辅色）
- 页脚左「NeuroDMS · 产品概览」，右页码

### ⑤ 配图清单
本 deck 不使用摄影图：安全类产品的叙事靠**结构与数据**。视觉载体为内联矢量图（层级图 / 流程链 / 矩阵），全篇统一为线描 + 色块，不混用插画或 3D。
