## 结构与改动

14 页的页面规划、品牌色板、语气规范见 `DESIGN.md`；每页源文件在 `slides/NN.slide`（DSL）。

v1.1.0 的三处结构性改动：

1. **功能改为「先共有、后差异」**：第 4–9 页讲两种交付形态都完整具备的能力
   （权限 / 密级外发 / 格式 / 审计 / 可验收数字），第 10–11 页才讲 SaaS 与本地部署的
   各自优势与选型判定。原「多租户隔离」页删除——它是 SaaS 的形态特征，不是共有能力，
   三条论证并入第 10 页「数据边界」行。
2. **行业页改成真坐标轴**：横轴外发频次、纵轴合规强度，九个行业定位（律所/设计院在右上），
   右侧三张"同一个问题的三种说法"点出痛点。
3. **视觉对齐森莘科创品牌体系**：墨 `#0A120E` / 纸 `#F5F7F2` / 森绿 `#0F5C40` /
   芽绿 `#C6EE4B`，点阵与阶梯母题，中文思源黑体。

## 重新生成

```bash
# 1. 从空白重建（upsert 不带 page-index 是追加）
slidep create "NeuroDMS-产品宣传-v1.1.0-20261112.pptx"
for i in $(seq -w 1 14); do
  slidep upsert-dsl "NeuroDMS-产品宣传-v1.1.0-20261112.pptx" --dsl-file "slides/$i.slide"
done

# 2. 截断每页 </p:sld> 之后的 DSL 源码尾巴（见 DESIGN.md §6）
#    不截断的话 PowerPoint 会提示修复
```

修改某一页时用 `--page-index N-1`；否则会追加成新的一页。
