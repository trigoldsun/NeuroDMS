## 为什么单列

电子签名不是"加一个签字按钮"：它要求 CA/TSA 选型、密钥与证书生命周期、签名—记录绑定、
WORM 归档与系统验证包，任何一环缺失都会变成"看起来签了、实际不可举证"。
在客户行业与信任服务选型确定前贸然开发，返工成本高于先做底座。

## 恢复条件

启动二期前需要先确认：

1. 目标行业优先级（GMP / 医疗器械 / 临床 / 通用合同）；
2. 第三方 CA/TSA 选型与预算（境内优先）；
3. 默认记录保留期；
4. 是否出海（eIDAS/QES）；
5. 是否接受分阶段宣称合规。

## 与现网的关系

现网的审计哈希链、密级与权限体系、水印与审批是可复用的底座；
二期方案里的 P0（非对称锚点 + 可信时间戳）会直接增强现有审计链，
但**不影响当前已上线的数据结构与接口**。
