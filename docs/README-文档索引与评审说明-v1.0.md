## 3. 设计的四个核心主张（评审重点）

1. **权限：15 原子位 + 6 档位 + 条件表达式**
   - 表达力对齐 AnyShare（含密级强制门、拒绝优先、能力封顶），交互对齐 Synology（勾选式、3 分钟可配完）。
   - 差异点：**条件可组合**（时间窗 × IP × 设备 × 配额 × MFA × 审批），且未知条件键一律 fail-closed。

2. **分享：两段式票据**
   - 链接 token 只换 5 分钟票据，字节流只认票据。
   - 一次性 = 单条原子 SQL 消费 + 票据短 TTL，解决"并发重放"与"泄漏窗口"。

3. **审计：fail-closed + 可离线自验**
   - 审计写不进 → 业务失败；哈希链 + 日结 Merkle 锚点 + 零依赖离线校验工具。

4. **形态：同一基线双形态**
   - 同一镜像、同一迁移集，`DOCVAULT_MODE` 切换私有化 / SaaS；租户隔离走「应用层 + RLS」双层。
