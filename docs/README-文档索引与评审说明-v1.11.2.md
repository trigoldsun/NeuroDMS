## 6. 门禁与自检

```bash
node scripts/check-doc-versions.mjs   # 文件名 / 头部 / 网页版 / 主文档 / 索引 五处版本一致
bash scripts/check.sh                 # 全量提交前检查（含上面一项）
```

发版时只改仓库根 `VERSION`，然后按门禁报告逐项修正；**不允许各文档自行编号**。
