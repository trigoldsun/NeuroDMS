# 文档中心小程序（原生 · 真实数据）

微信小程序：**文件浏览 / 预览 / 分享审批 / 搜索**。原生 WXML / WXSS / JS，无第三方框架、无 npm、无云开发。

- AppID：`wxdec20c98d9e34dec`
- 基础库：3.5.5
- 数据：**真实系统**（`https://ndms.neurongene.cn`）
- 版本：**跟随产品版本**（见上层 `VERSION`，当前 1.9.0）
- 源码位置：**主仓库 `miniprogram/`**（唯一可信源，有门禁与 CI）

## 1. 先决条件

1. **账号必须已登记并验证手机号**——小程序只对这类账号开放，未登记会在登录时被拒绝（403 `PHONE_NOT_REGISTERED`）。
   绑定入口在网页端：右上角账户 →「手机号」→ 口令 + 新号码验证码。
2. **微信公众平台 → 开发管理 → 服务器域名**，登记 `request` 与 `downloadFile` 合法域名（当前为 `ndms.neurongene.cn`）。
   > 这一条是**真机硬要求**：开发者工具可以关掉校验，真机不能。2026-11-15 的链路验收发现
   > 该域名并未登记——工具里必须关校验才能跑通，真机会直接报 "url not in domain list"。
   > 上线前必须在公众平台登记，或把 `utils/config.js` 的 `BASE_URL` 改成已登记的域名。
3. 短信验证码登录需要服务端配置阿里云**短信认证服务**（`DOCVAULT_SMS_*`）。未配置时该入口会提示"未开通"，不影响另外两种方式。
4. 审批提醒（订阅消息）需要服务端配置 `DOCVAULT_WX_APPID / DOCVAULT_WX_APPSECRET / DOCVAULT_WX_TODO_TEMPLATE`，
   且公众平台已添加同结构模板（字段 `thing1` 文件名称、`thing2` 申请人、`time3` 申请时间、`phrase4` 状态）。
   未配置时 `/v1/mp/config` 返回 `enabled=false`，界面**不显示**提醒入口（不是"点了报错"）。

## 2. 跑起来

1. 微信开发者工具 → 导入项目 → 选 **主仓库的 `miniprogram/` 目录**；
2. AppID 用上面的；
3. 本地联调：把 `utils/config.js` 的 `BASE_URL` 改成 `http://127.0.0.1:18090`，
   并新建 `project.private.config.json`（已在 `.gitignore`，不入库）写：
   ```json
   { "setting": { "urlCheck": false } }
   ```
   > 为什么关校验放私有文件：`project.config.json` 里保持 `urlCheck: true`，
   > 谁把"合法域名没登记"这件事带进主干，工具里会立刻红；本地开发用私有配置临时关掉。
4. 编译。未登录会落到登录页。

## 3. 登录：三种方式 + 二次验证

| 方式 | 填什么 | 说明 |
|---|---|---|
| 账号密码 | `zhangsan` 或 `zhangsan@组织标识` | 账号只在**一个**组织存在时可直接用；命中多个组织返回 409，要求补 `@组织标识`（不列出租户，防枚举） |
| 手机号密码 | 手机号 + **账号口令** | 手机号只用于定位账号，不新增一套密码 |
| 手机号验证码 | 手机号 + 6 位码 | 走阿里云短信认证服务；60 秒重发、5 分钟有效 |

服务端对小程序通道（`channel=mp`）额外要求手机号已验证——这道闸门在服务端，绕过界面也无效。

**二次验证（`mfa_required` 账号）**：口令通过后服务端返回 **202** + `challenge`，验证码发到登记邮箱；
界面切到"需要二次验证"，输码后调 `/v1/auth/mfa/verify` 换令牌。

> 202 不是成功。把它当 200 会保存空令牌，下一次请求 401，用户看到"登录已过期"——
> 原因与事实完全无关。这条由 `utils/request.js` 与 `scripts/test.js` 同时钉住。

## 4. 页签与功能

| 页签 | 内容 |
|---|---|
| 文件 | 顶部搜索入口 + 空间切换 + 面包屑 + **最近访问**（仅根目录）+ 文件列表（目录在前）；点文件进预览 |
| 审批 | 待我审批列表（密级、发起人、阶段、有效期）+ **审批提醒**入口；点进详情可通过/驳回 |
| 我的 | 组织、账号、手机号（掩码 + 已验证）、密级、角色、关于、**退出登录** |

- **搜索**（`pages/search`）：`GET /v1/search`，300ms 防抖 + 请求序号丢弃过期结果；
  "无结果"与"结果被截断"分开提示（截断时告诉用户补充关键词），不让人误以为组织里只有 20 个文件。
- **最近访问**：来自 `GET /v1/me/activity`（服务端活动日志），按对象去重取前 5 条。
  换设备也在，因为不是本地记录。
- **审批提醒**：微信订阅消息，**一次性**——授权一次只能发一条。按钮文案因此写"开启提醒"，
  不写"永久开启"；未配置通道时整块入口不渲染。

## 5. 文案与品牌从哪来

| 内容 | 来源 | 为什么不能写死 |
|---|---|---|
| 导航栏标题 / 登录页品牌 | `/v1/tenant/branding` 的 `productName` | 1.7.1 起"图标 / 名称 / 标题"三要素统一到租户；写死就会出现"网页端是森莘创新、小程序是文档中心" |
| 密级名称 | `/v1/classifications` | 租户可在「密级定义」改名；写死会让同一个 5 级文件有两种叫法 |
| 审批阶段 | 库里的 `none\|first\|owner\|done` | 判不存在的 `approver` 会让首段一律显示"审批中" |
| 提醒是否可用 | `/v1/mp/config` | 没配通道就不该出现按钮 |

登录前无法知道租户（同一域名多租户），所以登录页只显示产品兜底名（`utils/config.js` 的 `PRODUCT_FALLBACK`），
登录成功后立即按 `tenantSlug` 拉取品牌并覆盖标题。

## 6. 预览怎么实现

- 先 `wx.downloadFile`（带 `Authorization`）下载 `/v1/nodes/{id}/preview` 到临时文件；
  图片标签不能带请求头，PDF/Office 的 `openDocument` 也只接受本地路径。
- 按扩展名分流：图片 `previewImage`；PDF/Office `openDocument(showMenu:false)`；文本 `readFile` 后原生渲染；
  其它格式给出"不支持在线预览"的说明。
- 走 **preview** 而不是 **content**：前者只要求 Preview 权限，且 PDF 会叠加溯源水印；
  用下载接口做预览等于用更高权限看同一份文件。

## 8. 自检与测试

```bash
node scripts/check.js     # JSON 严格性、三件套、tabBar 图标、WXML 语法/闭合、事件绑定、旧模块残留
node scripts/test.js      # 202→MFA、密级名称、阶段枚举、格式化
```

主仓库还有一层门禁（提交前必跑，CI 也会跑）：

```bash
node scripts/check-miniprogram.mjs
```

它检查：版本 = 产品 `VERSION`、调用的每个 `/v1` 路径在后端存在、没有写死密级名称、
阶段只认四个值、每页都有 `applyTitle`（标题跟随租户）、`urlCheck` 保持开启，并顺带跑上面两个脚本。

## 9. 已知限制

- 短信认证服务仅支持中国大陆号码；短信签名为阿里云赠送签名（不是客户品牌）；
- 同一租户内本地账号与域账号同名时，小程序按"本地优先"尝试；域账号用户可能需在网页端选择登录方式；
- 只读 + 审批：不含上传/新建/发起分享；
- 预览依赖微信内置组件，PDF/Office 会离开当前页面（平台限制，不是降级）；
- 审批提醒是**一次性订阅**：用户授权几条就能发几条，余额在 `mp_subscription`；
- 搜索结果里的目录不支持下钻（会提示去文件页），因为搜索不返回目录路径。
